# Landing page design notes

Reviewed 2026-11-22. The landing page is an entry to a local demonstration, so its main job is to explain the workflow and make the next action obvious.

## References and decisions

- Nielsen Norman Group's [visual design principles](https://www.nngroup.com/articles/principles-visual-design/) describes hierarchy as guiding attention in order of importance. The page therefore has one primary heading, one process illustration, and one keyword action; brand metadata and decorative labels are secondary.
- Figma's [landing page examples](https://www.figma.com/resource-library/landing-page-examples/) recommends a strong hero visual and clear whitespace to communicate the product quickly. Here, the visual is a compact three-stage diagram because the project is a workflow, not a consumer product requiring lifestyle imagery.
- Stripe's [Payment Links page](https://stripe.com/en-at/payments/payment-links) uses a numbered "How it works" sequence. LedgerLens uses the same familiar left-to-right pattern for review events, compare ledger entries, and test a recovery.

The process labels describe the implemented demo. The landing page does not claim that the local keyword is user authentication or that a simulated recovery has been executed. It uses no assumed benchmark or operational statistics.
